# SBI PO 2027 Daily Planner 📚

A beautifully designed interactive daily study planner for SBI PO 2027 exam preparation. This web-based planner helps you maintain a structured study schedule with real-time progress tracking.

## Features ✨

- **Live Clock** - Real-time display of current time and date
- **Day Navigator** - Easy navigation between weekdays, Saturday (Revision), and Sunday (Recovery)
- **Smart Schedule Blocks** - Color-coded study blocks with:
  - Icons for quick visual identification
  - Time ranges in 12-hour format
  - Subject chips for categorization
  - Detailed descriptions for each block
- **Current Activity Tracking** - Shows what you should be doing right now
- **Day Progress Bar** - Visual indicator of how much of the study day is complete
- **Subject Color Legend** - Quick reference for all subjects:
  - 🟠 Saffron: Reasoning & Quantitative Aptitude
  - 🟢 Mint: English Language
  - 🔵 Sky Blue: GA / Banking
  - 🟣 Lavender: Revision
  - 🔴 Rose: Coaching / Breaks
- **Personalized Tips** - Study optimization advice and motivation
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile

## Weekly Structure 📅

### Weekdays (Mon-Fri): Coaching + Study Days
- 07:00 AM to 11:00 PM structured study
- Coaching classes integrated
- 5 main subjects covered daily
- Break times scheduled strategically
- Sleep target: 11 PM

### Saturday: Revision Day
- Focus on week's revision
- Full mock test attempt
- Mock analysis and weak area practice
- Weekly mistakes journal

### Sunday: Recovery + Deep Learning
- Slower morning start
- Banking awareness deep study
- Comprehensive practice
- Next week planning
- Sleep early: 10:30 PM

## Schedule Highlights 🎯

Each day includes:
- **Wake Up Routine** - Fresh start, water, and light stretch
- **Current Affairs** - Stay updated with news
- **Core Subjects** - Quant, Reasoning, English, Banking
- **Strategic Breaks** - Tea, food, and rest periods
- **Mock Tests** (Saturday) - Full-length practice exams
- **Revision** - Daily and weekly review sessions
- **Sleep** - Optimized for memory consolidation

## How to Use 🚀

1. Open `index.html` in any web browser
2. The current day is highlighted automatically
3. Click on any day tab to view that day's schedule
4. The "Right now" banner shows your current activity
5. Progress bar updates in real-time on the current day

## Key Study Tips 💡

1. **Anki Flashcards** - 10 cards/day for vocab and banking terms
2. **Phone Discipline** - Limited to 22:00-22:30 on weekdays
3. **Hydration** - Keep water bottle at study desk
4. **Active Writing** - Write 5 key points from memory daily
5. **Sleep Priority** - Move sleep to 11 PM for memory consolidation
